## 技术决策记录

| 决策 | 结论 | 原因 |
|------|------|------|
| 实验一平台 | 先网页版，后小程序 | 先给老师看，认可后再做小程序 |
| 实验二平台（旧）| H5 网页 | three-miniprogram 已死，MindAR 浏览器直接可用 |
| 实验二平台（新）| Unity + Vuforia | 老师要求，识别更稳定，渲染效果更好 |
| 模型导出格式（新）| FBX | Unity 原生支持，空物体+磁感线一起导出 |
| 副边电压 | ~1.8V 直流 | 实测无线充电模块输出 |
| 电压表量程 | 0-3.3V | 匹配 ESP32 ADC |
| 模型工具 | Blender → .glb | 几百面简单模型 |
| 数据传输 | BLE → Web Bluetooth | 网页版用 Web Bluetooth API |
| 导线建模 | 贝塞尔曲线 | 比手搓圆柱快 10 倍，弧度自然 |
| 导出格式 | glTF Binary (.glb) | 单文件，Web 标准，Three.js 原生支持 |
| 磁感线建模 | Blender 预制 + 代码显隐 | 贝塞尔曲线+倒角+圆锥箭头+旋转复制 |
| 距离计算 | 屏幕像素 2D 距离 | 不受其他目标干扰，稳定可靠 |
| 磁感线切换 | HTML 按钮 | A-Frame raycaster 在手机端不可靠 |
| 目标粘性保持 | 丢失后保持 3 秒 | 解决识别图靠近时互相遮挡 |
| 导线可见性 | MeshBasicMaterial + depthTest:false | 不受光照影响，优先渲染 |
