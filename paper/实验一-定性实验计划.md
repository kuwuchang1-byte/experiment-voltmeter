# 实验一：定性实验计划

> 目标：测量线圈距离对无线输电效率的影响
> 时间：2026-05-29 晚上
> 工具：导轨 + 刻度尺 + 万用表 + ESP32 电压表系统

---

## 实验一：距离对输电电压的影响（必做）

### 器材

| 器材 | 用途 | 数量 |
|------|------|------|
| 导轨 | 固定发射线圈，精确控制距离 | 1 根 |
| 发射线圈（XKT F-19 原边） | 固定在导轨一端 | 1 个 |
| 接收线圈（XKT F-19 副边） | 可在导轨上移动 | 1 个 |
| 12V 电源适配器 | 给发射端供电 | 1 个 |
| ESP32 + 电路板 | 采集副边电压 | 1 套 |
| 刻度尺/游标卡尺 | 读取距离 | 1 把 |
| 万用表 | 校验 ESP32 读数 | 1 个 |

### 实验步骤

1. **固定发射端**：将发射线圈固定在导轨一端，接通 12V 电源
2. **初始位置**：接收线圈紧贴发射线圈（距离 ≈ 0mm），记录电压
3. **逐距离测量**：每增加 5mm 记录一次电压，直到输电完全中断
4. **每个距离测 3 次**：取平均值，减小误差

### 建议测量点

| 距离（mm） | 预期现象 |
|-----------|---------|
| 0 | 电压最高（~3.3V 或更高） |
| 5 | 电压略降 |
| 10 | 电压明显下降 |
| 15 | 电压急剧下降 |
| 20 | 电压很低 |
| 25 | 接近 0 |
| 30+ | 可能完全无输出 |

**注意**：XKT F-19 的有效距离约 0-80mm，但实际陡变区可能在 0-30mm 内。根据实际测试情况调整测量点，变化剧烈的区间多测几个点。

### 数据处理

1. 绘制"电压-距离"曲线（X 轴：距离 mm，Y 轴：电压 V）
2. 标注陡变区间（电压骤降的区域）
3. 计算电压梯度 dV/dx（单位：V/mm），量化敏感程度
4. 与理论公式对比（互感系数与距离的关系）

## 实验二：有无谐振电容的影响（可选）

### 原理

XKT F-19 模块内部有谐振电路。如果有外部谐振电容与线圈配合，可以增强耦合效率。

### 实验步骤

1. **有谐振电容**：正常连接，测量 5 个距离点的电压
2. **无谐振电容**：断开谐振电容（或用旁路线替代），测量同样 5 个距离点的电压
3. **对比两组数据**

## 包装模块（黑箱化）

在做实验之前或之后，把电路整理进黑箱：

### 需要做的事情

1. **发射端黑箱**：把发射线圈驱动电路 + 12V 电源接口装进黑箱
2. **接收端黑箱**：把接收线圈 + ESP32 + 滤波电路装进黑箱
3. **接线柱**：黑箱两端装接线柱，方便连接
4. **标识**：贴标签标注"发射端"、"接收端"、"IN"、"OUT"

### 注意事项

- 黑箱内部用热熔胶或扎带固定，防止晃动
- 接线柱要牢固，方便反复插拔
- 预留 ESP32 的 USB 口位置（充电/调试用）
- 预留散热孔（ESP32 和电源芯片会发热）
