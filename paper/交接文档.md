## 四、技术架构

### 实验一

```
ESP32 (ADC采集) → BLE广播 → 手机浏览器 (Web Bluetooth) → Canvas电压表 + 实时曲线
```

- ESP32 服务 UUID：0000fff0-0000-1000-8000-00805f9b34fb
- ESP32 特征 UUID：0000fff1-0000-1000-8000-00805f9b34fb
- 设备名称：ESP32-Voltmeter
- 电压量程：0-3.3V
- 副边电压：约 1.8V 直流

### 实验二（Unity + Vuforia）

```
手机摄像头 → Vuforia 图像识别 → Unity 3D 渲染
```

- 4 个 Image Target
- 7 个 C# 脚本
- FBX 模型含空物体（接线点标记）
