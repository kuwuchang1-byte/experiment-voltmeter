# 《物理实验》期刊论文写作风格参考
> 基于 3 篇指定论文的分析：方春艳(2024)、李伟(2022)、列晓东(2017)

---

## 一、论文结构

三篇论文均遵循统一结构：

```
标题（含副标题，20~40字）
作者（单位）
摘要（100~200字，一段话）
关键词（3~5个）
中图分类号 / 文献标识码 / DOI

0 引言（1~2段，200~400字）
1 系统/装置设计（原理+硬件+软件）
2 实验过程与结果（数据表+图+分析）
3 结束语（100~300字）
参考文献
```

---

## 二、各部分写法

### 2.1 标题
- 较长（20~40字），含技术手段+物理对象+研究类型
- 常用副标题（破折号）限定范围
- 实例：
  - 《基于Uni-app框架的高中物理实验App设计——以加速度传感器为例》
  - 《STEAM课程理念下的高中物理实验设计——以基于Arduino探究小车速度随时间变化规律为例》
  - 《基于STM32的向心力探究演示仪的研制》

### 2.2 摘要
- 100~200字，一段话，不分段
- 结构：问题/背景(1句) → 本文做了什么(1~2句) → 怎么做的(1句) → 结果(1句) → 意义(1句)
- 不出现"本文""本研究"等自指词
- 最后一句通常是"为……提供了参考/思路"

### 2.3 关键词
- 3~5个，物理概念+技术手段
- 实例：实验应用程序；传感器；加速度；气垫导轨实验

### 2.4 引言
- 200~400字，1~2段
- 引用文献：0~8篇（方春艳8篇最多，列晓东0篇）
- 三段论：背景 → 问题 → 本文目的
- 典型开头："在……背景下，……已成为……的重要组成部分"
- 典型结尾："本文利用/基于XX，设计/研制了YY，为……提供了参考"

### 2.5 正文
- 段落短，3~6句一段
- 高频动词：利用、探究、测量、验证、演示、设计、研制、采集、分析
- 高频句式："利用XX测量YY""由图X可知""从表X可以看出"
- 图表标注：`图X  描述性名称` `表X  描述性名称`
- 数据处理：数据表 → 图表展示 → 文字分析（三明治结构）

### 2.6 结束语
- 100~300字，一段话
- 结构：本文做了什么 → 结果 → 优点(2~3句) → 展望(可选)
- 典型句式："该方法/装置具有……优点""为……提供了参考"

### 2.7 参考文献
- 格式：`[序号] 作者. 标题[J]. 期刊名, 年份, 卷(期): 页码.`
- 数量：3~8篇
- 来源：《物理实验》《物理教师》《物理通报》等教学类期刊为主

## 三、核心风格特征

1. **实用导向**：全文围绕"这个实验怎么做、效果好不好"展开
2. **图文并茂**：每个装置、步骤都配图
3. **数据说话**：强调"实验结果与理论值的相对偏差"
4. **教师视角**：写作视角是"一线教师/研究生向同行介绍好用的实验"
5. **不做过度讨论**：没有长篇误差分析，点到为止
6. **公式简洁**：只列核心公式，不做推导
7. **强调可操作性**：器件型号、操作步骤描述详尽
8. **语言平实直白**：不玩修辞，每句话都是信息句
